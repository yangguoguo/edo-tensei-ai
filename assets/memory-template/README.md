# Portable AI Memory

This is a private, user-owned context library. Newer user statements override stored memory.

Read order:

1. `memory-index.md`
2. Core files listed there
3. `open-questions.md`
4. Relevant files in `archive/` only when needed

Store distilled memory rather than a rolling archive of recent conversations. Keep at most 6 representative discussion summaries in `archive/` when they preserve important context that cannot be reduced to a core profile bullet. Keep only evidence-backed reusable capabilities in `tools-and-skills.md`, and demote items unused for 3 months instead of applying a fixed count limit. Use `history/change-log.md` only as a compact audit trail of real memory changes, with at most 12 detailed entries. Do not put passwords, tokens, cookies, private keys, recovery codes, identity-document numbers, or exact financial account details here.
